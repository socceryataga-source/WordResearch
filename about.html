About this site.

このサイトは、英語の新出語句から語彙のつながりを探すための学習ツールです。英単語を入力すると候補を表示します。候補をクリックするとその語だけをコピーできます。スプレッドシートは別途、先生から配布されたものを使ってください。

検索データについて

Synonyms / Antonyms: Free Dictionary API と Datamuse API の候補を統合します。Word Family: サイト内の word-families.js に登録した確認済みの語群を表示します（網羅的な辞書ではありません）。Word Partners: Datamuseのコーパス統計から共起候補を組み合わせたもので、コロケーションとしての自然さが保証されるものではありません。

語によっては複数の意味や品詞があります。検索結果が教科書の文脈に合うか、必ず確認してください。検索候補にないことは「その語が存在しない」という意味ではありません。

外部サービスと注意点

検索時に入力した単語は、外部の Free Dictionary API と Datamuse API に送信されます。このサイト自体には入力単語や個人情報を保存するサーバー機能はありません。ブラウザのクリップボードへコピーする操作はユーザーのクリック時のみです。

重要： Datamuseは2027年2月1日からAPIキー必須になると公式に予告しています。この静的サイトはAPIキーを公開しない設計のため、その日以降、Datamuseに依存する検索が使えなくなる可能性があります。辞書APIによる検索と登録済みの派生語は、別系統として動作する設計です。

SKELLは外部サイトへのリンクのみです。SKELL自体のデータを自動取得する仕様ではありません。
